Knitty's first public release manages Core Keeper mod profiles from a command-line
interface or an interactive terminal UI.

## What's included

- Search mod.io, add and remove mods, review updates, and synchronize Core Keeper installations.
- Share `knitty.yaml` and `knitty.lock` to reproduce a mod selection across players.
- Preview deployment with `--dry-run` before applying changes.
- Save your own mod.io credentials and Steam library settings outside shared profiles.
- Browse the Valheim catalog through Thunderstore; Valheim installation is not supported yet.

## Downloads

| File | Use |
| --- | --- |
| `knitty-0.7.0-windows-x64.zip` | Windows x64, including Java. Extract the entire ZIP and run `knitty/knitty.exe` from a terminal. |
| `knitty-0.7.0-jvm.tar.gz` | Executable JAR for Java 21+. Run `java --enable-native-access=ALL-UNNAMED -jar knitty.jar`. The included Unix launcher expects the AUR installation layout. |
| `knitty-0.7.0-source.tar.gz` | Buildable Knitty sources. Extract and run the checked-in Kotlin Toolchain launcher from the `knitty` directory. |

SHA-256 sidecars accompany the archives. AUR (`knitty` and `knitty-bin`) and WinGet
submission files are prepared; registry publication is a separate step.

## Getting started

On Windows, open a terminal in the extracted `knitty` directory:

```powershell
.\knitty.exe auth
.\knitty.exe setup
.\knitty.exe tui core-keeper --profile "$env:USERPROFILE\KnittyProfiles\core-keeper"
```

For a manually extracted JVM archive, replace `.\knitty.exe` with
`java --enable-native-access=ALL-UNNAMED -jar knitty.jar` and choose a writable
profile directory. `auth` requires your own API path and key from
[mod.io API Access](https://mod.io/me/access).

Close Core Keeper before applying changes. Keep profiles outside the extracted
application directory, and share only `knitty.yaml` and `knitty.lock`; each player
configures their own credentials and installation location.
